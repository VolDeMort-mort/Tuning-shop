# Модель UML

[← Назад: План реалізації](../docs/implementation-plan.md) | [Далі: Варіанти використання →](../docs/use-cases.md)

Тут зберігається редаговане джерело командних Use Case, Class і State Machine Diagram: Use Case Diagram — `use-case.svg` (векторний рисунок, редагується в Inkscape або текстовому редакторі), Class і State Machine Diagram — PlantUML: `class-diagram.puml`, `order-state-machine.puml`.
Експорт діаграм у PNG розміщено в `docs/images/`; `use-case.svg` експортують у PNG з редактора або браузера, а після зміни `.puml` його оновлюють командою `java -jar plantuml.jar -tpng -charset UTF-8 *.puml`.
