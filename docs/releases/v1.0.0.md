## Можливості v1.0

- Вхід працівників за логіном і паролем; функції обмежено роллю Менеджер / Майстер / Керівник (FR-01).
- Реєстрація й редагування клієнтів і автомобілів; пошук за телефоном, частиною ПІБ, держномером, VIN (FR-02 – FR-05, FR-18).
- Оформлення замовлення з роботами й майстрами; одне активне замовлення на автомобіль (FR-06 – FR-08).
- Життєвий цикл замовлення за State Machine: «Нове» → «В роботі» → «Готове до видачі» → «Видане», скасування з причиною, історія статусів (FR-09, FR-12 – FR-15).
- Робоче місце майстра: власні роботи й зміна статусу лише вперед (FR-10, FR-11).
- Поточні та завершені замовлення з фільтрами, картка замовлення з прогресом і сумою (FR-16, FR-17, FR-19).
- Облік деталей для робіт (FR-20) і відстеження стану клієнтом без входу (FR-21).

## Обмеження v1.0

- Свідомо відкладено за SRS: кабінет клієнта, адміністрування облікових записів, оплата, складський облік, пошук замовлення за номером.
- Одночасне редагування одного замовлення кількома менеджерами не захищене від конкурентних змін.
- Пароль навчальних облікових записів однаковий для ролі; змінювати паролі через інтерфейс у v1.0 не можна.

## Запуск

Інструкція в пакеті — [RUN.md](RUN.md). Коротко: .NET 8 Runtime, `ConnectionStrings__Tuning="Data Source=<абсолютний шлях>"`, `dotnet TuningShop.Api.dll --urls http://localhost:5080`.

## Збирання пакета

```powershell
git switch main; git pull --ff-only
powershell -ExecutionPolicy Bypass -File scripts/release.ps1 -Version 1.0.0
git tag -a v1.0.0 -m "Перша перевірена версія"; git push origin v1.0.0
```

Скрипт відмовляється збирати пакет із незафіксованими змінами, запускає тести, збирає клієнт і сервер, записує коміт у `BUILD-INFO.txt`, створює архів і `.sha256`. Після перевірки пакет не перезбирається.
