# Activity Diagram UC-03 «Оформити замовлення»

[← Назад: Варіанти використання](use-cases.md) | [Далі: Activity UC-04 →](activity-UC-04.md)

Діаграма показує послідовність дій, точки прийняття рішень та альтернативні завершення сценарію.

```mermaid
flowchart TD
    A([Початок]) --> B["Знайти автомобіль за держномером або VIN (UC-11)"]
    B --> C{"Знайдено?"}
    C -- Ні --> D["Зареєструвати автомобіль (UC-02)"]
    D --> F
    C -- Так --> F["Ініціювати створення замовлення"]
    F --> G{"Є активне замовлення?"}
    G -- Так --> H["Показати номер активного замовлення"]
    H --> Z1([Завершення без змін])
    G -- Ні --> I["Ввести опис побажань клієнта"]
    I --> J["Додати роботу: вид, опис, орієнтовна вартість"]
    J --> K{"Дані коректні?"}
    K -- Ні --> L["Показати помилки біля полів"]
    L --> J
    K -- Так --> N{"Майстра обрано?"}
    N -- Так --> O["Призначити майстра"]
    N -- Ні --> P["Попередити: робота без майстра"]
    O --> Q{"Ще робота?"}
    P --> Q
    Q -- Так --> J
    Q -- Ні --> S["Підтвердити і зберегти замовлення: номер, дата, статус «Нове», запис в історії"]
    S --> T["Показати картку замовлення"]
    T --> Z2([Успішне завершення])
```
