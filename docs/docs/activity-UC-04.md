# Activity Diagram UC-04 «Змінити статус замовлення»

[← Назад: Activity UC-03](activity-UC-03.md) | [Далі: Activity UC-05 →](activity-UC-05.md)

Діаграма показує послідовність дій, точки прийняття рішень та альтернативні завершення сценарію.

```mermaid
flowchart TD
    A([Початок]) --> B["Відкрити картку замовлення (UC-06 / UC-07)"]
    B --> C{"Статус фінальний?"}
    C -- Так --> D["Показати картку лише для перегляду"]
    D --> Z0([Завершення без змін])
    C -- Ні --> E["Показати дозволені дії"]
    E --> F{"Обрана дія"}
    F -- "Передати в роботу" --> G{"Майстри призначені всім роботам?"}
    F -- "Позначити готовим" --> H{"Усі роботи виконано?"}
    F -- "Видати автомобіль" --> I["Зафіксувати дату видачі"]
    F -- "Скасувати" --> J["Ввести причину"]
    J --> K{"Причину введено?"}
    K -- Ні --> J
    G -- Ні --> R1["Відмовити, показати роботи без майстра"]
    H -- Ні --> R2["Відмовити, показати невиконані роботи"]
    R1 --> Z1([Завершення: статус не змінено])
    R2 --> Z1
    G -- Так --> S1["Статус «В роботі»"]
    H -- Так --> S2["Статус «Готове до видачі»"]
    I --> S3["Статус «Видане»"]
    K -- Так --> S4["Статус «Скасоване», зберегти причину"]
    S1 --> T["Додати запис до історії статусів"]
    S2 --> T
    S3 --> T
    S4 --> T
    T --> U["Показати оновлену картку"]
    U --> Z2([Успішне завершення])
```
