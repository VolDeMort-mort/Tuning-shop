# Activity Diagram UC-05 «Виконати призначену роботу»

[← Назад: Activity UC-04](activity-UC-04.md)

Діаграма показує послідовність дій, точки прийняття рішень та альтернативні завершення сценарію.

```mermaid
flowchart TD
    A([Початок]) --> B["Відкрити перелік призначених робіт"]
    B --> C{"Є призначені роботи?"}
    C -- Ні --> D["Показати порожній перелік"]
    D --> Z0([Завершення])
    C -- Так --> E["Обрати роботу"]
    E --> E1["Переглянути деталі роботи та їхній стан (UC-09)"]
    E1 --> E2["Обрати дію зміни статусу"]
    E2 --> F{"Робота своя, замовлення «В роботі»?"}
    F -- Ні --> G["Відхилити зміну, показати причину"]
    G --> Z1([Завершення: статус не змінено])
    F -- Так --> H{"Статус роботи"}
    H -- "«Заплановано»" --> I["Встановити «Виконується»"]
    H -- "«Виконується»" --> J["Встановити «Виконано»"]
    H -- "«Виконано»" --> K["Зміна недоступна"]
    K --> Z1
    I --> L["Зберегти статус і час зміни"]
    J --> L
    L --> M["Оновити прогрес «виконано X з Y»"]
    M --> M1["Перевірити умову зміни статусу замовлення (UC-04)"]
    M1 --> N{"Усі роботи виконано?"}
    N -- Так --> O["Позначити для менеджера: «усі роботи виконано»"]
    N -- Ні --> Z2([Успішне завершення])
    O --> Z2
```
